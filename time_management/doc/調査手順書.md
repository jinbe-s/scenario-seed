# TRPGセッション時間管理アンケート 調査手順書

## 1. 概要

### 1.1 調査目的
本調査は、TRPGセッションにおける時間管理の実態を明らかにし、効果的な時間管理手法を体系化することを目的とする。アンケート回答データから傾向を抽出し、同人誌形式でTRPGコミュニティに還元する。

### 1.2 データ概要
- **データソース**: Googleフォームで収集したアンケート回答
- **データファイル**: `time_management/データ.csv`
- **回答数**: 1,280件
- **総行数**: 1,281行（ヘッダー1行 + データ1,280行）
- **列数**: 29列
- **調査対象**: TRPGプレイヤー・ゲームマスター

**注意**: 元データには自由記述フィールド内の改行により行が分割されていたため、データクリーニングを実施済み。元データは `データ_original_backup.csv` としてバックアップ保存。

### 1.3 主要な調査項目
1. TRPGセッションの時間管理についての概要
2. GMの時間管理手法と工夫
3. 時間超過の原因と対策
4. 時間管理のコツとベストプラクティス

## 2. データ構造の確認（事前準備）

### 2.1 列構造の把握
以下の主要な列を確認済み：

**基本属性**
- `経験年数`: 1年未満 / 1〜3年 / 4〜6年 / 7年以上
- `形態`: オンラインセッション（単発/キャンペーン）、オフライン（対面）、コンベンション参加
- `参加立場`: 主にPL / 主にGM / 半々 など
- `システム`: CoC6版、CoC7版、シノビガミ、D&D、SW2.5など

**時間意識関連**
- `終了時間意識`: 常に意識している / ある程度は意識している / あまり意識していない など
- `時間意識_理由`: 自由記述
- `時間超過`: ほとんどない / たまにある / よくある など
- `時間超過_原因`: 自由記述

**GM向け質問**
- `GM回答有無`: GMとして回答しているか
- `GM_時間配分`: 時間配分の方法（自由記述）
- `GM_時間意識工夫`: 時間を意識するための工夫（自由記述）
- `GM_時間超過対処`: 時間超過時の対処法（自由記述）
- `GM_時間管理と満足度`: 時間管理と満足度のバランスについての考え（自由記述）
- `GM_コツ`: 時間管理のコツ（自由記述）

**システム別フラグ**
- `CoC6`, `CoC7`, `isCoC`, `エモクロア`, `シノビガミ`, `インセイン`, `D&D`, `DX3rd`, `SW2.0`, `SW2.5`, `その他`

### 2.2 システム分類の注意点

**重要**: システムの記入は自由記述のため表記ゆれが存在する。以下の分類方針に従って分析を行う。

#### 2.2.1 クトゥルフ神話TRPG（CoC）の扱い
クトゥルフ神話TRPGは本アンケートにおいて最も回答数が多いシステムであり、以下の3つのパターンが存在する：

1. **CoC6版のみ**: `CoC6` = 1, `CoC7` = 0, `isCoC` = 1
   - CoC6版のみプレイしている回答者

2. **CoC7版のみ**: `CoC6` = 0, `CoC7` = 1, `isCoC` = 1
   - CoC7版のみプレイしている回答者

3. **CoC（版不明）**: `CoC6` = 0, `CoC7` = 0, `isCoC` = 1
   - 自由記述で「CoC」「クトゥルフ」などと記載があり、版が判別できない回答者
   - または6版・7版両方をプレイしている可能性がある回答者

#### 2.2.2 システム別分析の方針

分析においては以下の複数の軸で集計を行う：

**軸1: CoC vs それ以外**
- `isCoC` = 1: クトゥルフ神話TRPG全般（版問わず）
- `isCoC` = 0: それ以外のシステム

**軸2: CoC版別 vs それ以外**
- `CoC6` = 1 または `CoC7` = 1: 版が特定できるCoC
- `isCoC` = 1 かつ `CoC6` = 0 かつ `CoC7` = 0: 版不明のCoC
- `isCoC` = 0: それ以外のシステム

**軸3: 主要システム別**
- CoC6版
- CoC7版
- CoC（版不明）
- エモクロア
- シノビガミ
- インセイン
- D&D
- DX3rd
- SW2.0
- SW2.5
- その他

**注意**: 回答者は複数システムをプレイしている可能性があるため、各フラグは独立している。集計時は重複を許容する。

#### 2.2.3 分析上の着目点

1. **CoCとそれ以外で時間管理に違いはあるか**
   - CoCはRP重視の傾向があるため、時間超過原因として「RP要因」が多い可能性
   - CoCプレイヤーの時間意識の特徴

2. **CoC6版とCoC7版で違いはあるか**
   - ルールの違いによる時間管理の差異
   - 版ごとのプレイヤー層の違い

3. **主要システムごとの特性**
   - 戦闘重視システム（D&D、SW2.5、DX3rd）: 戦闘時間の管理が課題？
   - RP重視システム（CoC、エモクロア）: RP時間の管理が課題？
   - シーン制システム（シノビガミ）: 時間管理がしやすい？

### 2.3 データクリーニング方針
- 欠損値の扱い: GM回答は`GM回答有無`列で判定
- 自由記述の前処理: 改行・空白の正規化（実施済み）
- システム名の統一: フラグ列を優先して使用

## 3. 調査手順

### 3.1 【第1段階】基礎集計：全体像の把握

#### 3.1.1 回答者属性の集計
**目的**: アンケート回答者の基本的なプロフィールを把握する

**分析項目**:
1. 経験年数別の回答数・割合
2. 参加形態別の回答数・割合（オンライン/オフライン/コンベンション）
3. 参加立場別の回答数・割合（PL中心/GM中心/半々）
4. システム別の回答数・割合（複数選択可能性を考慮）

**アウトプット形式**:
- 各項目の集計表（回答数、割合）
- 棒グラフまたは円グラフ
- システム別は上位10件程度を抽出

**実装方法**:
- Python（pandas）での集計
- matplotlib/seabornでのグラフ作成

#### 3.1.2 時間意識の全体傾向
**目的**: 全体としてどの程度時間を意識しているかを把握する

**分析項目**:
1. `終了時間意識`の分布（常に/ある程度/あまり/全く）
2. `時間超過`の頻度分布（ほとんどない/たまに/よくある）
3. GM回答者の割合

**アウトプット形式**:
- 集計表とグラフ
- 時間意識と時間超過のクロス集計表

---

### 3.2 【第2段階】クロス集計：属性による違いの分析

#### 3.2.1 属性別の時間意識比較
**目的**: システム、経験年数、参加形態、立場などの違いで時間管理意識に差があるか確認する

**分析項目**:
1. **経験年数 × 終了時間意識**
   - 経験が長いほど時間意識が高いか？

2. **参加立場 × 終了時間意識**
   - GMの方がPLより時間意識が高いか？

3. **参加形態 × 終了時間意識**
   - オンライン/オフライン/コンベンションで意識に差があるか？

4. **システム × 終了時間意識**
   - **軸1**: CoC vs それ以外（`isCoC`フラグで判定）
   - **軸2**: CoC6版 / CoC7版 / CoC版不明 / それ以外
   - **軸3**: 主要システム別（CoC、エモクロア、シノビガミ、D&D、SW2.5など）
   - システムの特性（戦闘重視/RP重視、シーン制など）との関連性を考察

**アウトプット形式**:
- クロス集計表（件数と割合）
- 積み上げ棒グラフまたはヒートマップ
- 特徴的な傾向のテキスト記述

**統計的検討**:
- カイ二乗検定などで有意差を確認（可能であれば）
- ただし、学術論文ではないため、視覚的な傾向の提示を重視

#### 3.2.2 属性別の時間超過頻度比較
**分析項目**:
1. **経験年数 × 時間超過頻度**
2. **参加立場 × 時間超過頻度**
3. **参加形態 × 時間超過頻度**
4. **システム × 時間超過頻度**
   - 軸1: CoC vs それ以外
   - 軸2: CoC版別分析
   - 軸3: 主要システム別

**アウトプット形式**:
- 3.2.1と同様

---

### 3.3 【第3段階】自由記述のテキストマイニング

#### 3.3.1 時間意識の理由分析
**対象列**: `時間意識_理由`

**分析手順**:
1. **頻出キーワードの抽出**
   - 形態素解析（MeCabなど）で名詞・動詞を抽出
   - 頻出語TOP30程度をリスト化

2. **カテゴリ分類**
   - 回答を類似性でグルーピング
   - 例：「睡眠時間確保」「翌日の仕事」「体調管理」→【健康・生活】
   - 例：「会場の時間」「終電」→【物理的制約】
   - 例：「参加者への配慮」「約束を守る」→【マナー・配慮】

3. **カテゴリ別の集計**
   - 各カテゴリに該当する回答数をカウント

**アウトプット形式**:
- 頻出キーワードの表
- ワードクラウド
- カテゴリ分類結果の表と円グラフ
- 各カテゴリの代表的な回答を引用

#### 3.3.2 時間超過原因の分析
**対象列**: `時間超過_原因`

**分析手順**:
1. **頻出パターンの抽出**
   - 「RPが盛り上がった」「戦闘が長引いた」「相談が長引いた」など

2. **カテゴリ分類**
   - 例：【RP要因】RPが盛り上がった、PLのRP速度が遅い
   - 例：【戦闘要因】戦闘が長引いた、ダイス目が悪い
   - 例：【相談要因】PL会議が長引いた、情報共有に時間がかかった
   - 例：【GM要因】情報提示が遅い、シナリオ進行の見積もりミス
   - 例：【その他】雑談が多い、技術的トラブル

3. **立場別（PL/GM）での原因傾向の比較**

**アウトプット形式**:
- カテゴリ別集計表とグラフ
- 原因と対策の対応表（3.4と連携）
- 具体的な回答の引用集

### 3.4 【第4段階】GM向け詳細分析

#### 3.4.1 GM回答者のフィルタリング
**条件**: `GM回答有無` = "ゲームマスター経験者向けの質問に回答する"

**確認事項**:
- GM回答者数の集計
- GM回答者の経験年数・システム分布

#### 3.4.2 GM時間配分の手法分析
**対象列**: `GM_時間配分`

**分析手順**:
1. **手法のパターン抽出**
   - 「シーンごとに目安時間を設定」
   - 「予備日を設定」
   - 「テストプレイで計測」
   - 「PLのタイプ速度を確認」
   - 「余裕を持った日程」

2. **カテゴリ化**
   - 【事前準備型】: テストプレイ、シナリオ読み込み、目安時間設定
   - 【柔軟対応型】: PLの様子を見て調整、予備日確保
   - 【詳細管理型】: シーンごとの時間設定、進捗チェック
   - 【経験則型】: 過去の経験から見積もり

**アウトプット形式**:
- 手法別の実施割合
- 経験年数別の手法傾向（経験が長いほど詳細管理？）
- 具体的な手法の引用集

#### 3.4.3 GM時間意識の工夫分析
**対象列**: `GM_時間意識工夫`

**分析手順**:
1. **工夫のパターン抽出**
   - 「時計を見る」「進捗を共有」「PLに残り時間を伝える」
   - 「情報タブの整理」「シーン単位での時間管理」

2. **カテゴリ化**
   - 【可視化】: 時計配置、進捗表示、タイマー使用
   - 【コミュニケーション】: PLへの時間共有、「まとめてください」の声かけ
   - 【環境整備】: 情報タブ整理、ツール活用
   - 【なし/特になし】: 特に工夫していない

**アウトプット形式**:
- カテゴリ別実施割合
- 時間超過頻度との相関（工夫している人ほど超過が少ない？）
- 効果的な工夫の引用集

#### 3.4.4 GM時間超過対処法の分析
**対象列**: `GM_時間超過対処`

**分析手順**:
1. **対処法のパターン抽出**
   - 「判定を省略」「情報提示を簡略化」「シーンカット」
   - 「RPの時間制限」「追加日程の相談」「描写の簡略化」

2. **カテゴリ化**
   - 【削減系】: 判定省略、シーンカット、描写簡略化
   - 【調整系】: RP時間制限、PLへの声かけ
   - 【延長系】: 追加日程、予定時間の延長相談
   - 【なし】: 特に対処していない

**アウトプット形式**:
- カテゴリ別実施割合
- 対処法の組み合わせパターン（複数回答の場合）
- 効果的と思われる対処法の抽出

#### 3.4.5 時間管理と満足度のバランス
**対象列**: `GM_時間管理と満足度`

**分析手順**:
1. **スタンスのパターン抽出**
   - 「時間厳守優先」「満足度優先」「両立/バランス」「メンバー次第」

2. **定量化の試み**
   - 「時間：満足度＝7:3」のような記述から比率を抽出
   - 記述内容から傾向をカテゴリ化

3. **経験年数・システムとの関連**
   - 経験が長いほど時間厳守？それとも柔軟？

**アウトプット形式**:
- スタンス別の分布
- 定量的な比率の平均値（可能であれば）
- 各スタンスの代表的な意見を引用

#### 3.4.6 GMのコツまとめ
**対象列**: `GM_コツ`

**分析手順**:
1. **コツの抽出と分類**
   - 【事前準備】: シナリオ読み込み、テストプレイ、目安時間設定
   - 【進行管理】: こまめな時間確認、進捗共有、PLへの声かけ
   - 【柔軟性】: 予備日確保、キリの良いところで終わる
   - 【コミュニケーション】: PLへの相談、状況の説明
   - 【マインド】: 時間を守ることの重要性、責任転嫁も必要

2. **頻出コツのランキング**

3. **有効そうなコツと効果が疑問なコツの分類**
   - 時間超過が少ない人が実践しているコツ
   - 逆に時間超過が多い人が実践しているコツ

**アウトプット形式**:
- コツのカテゴリ別一覧
- 頻出コツTOP10
- 「これは効く！」と思われるコツの引用集
- 「意外と効かない？」コツの考察

### 3.5 【第5段階】追加発見：データから導き出せる新たな視点

#### 3.5.1 想定される追加分析項目

**1. システム特性と時間管理の関係**
- **仮説1**: CoCとそれ以外で時間管理の傾向に違いはあるか？
  - CoCはRP重視のため、時間超過原因として「RP要因」が多い可能性
  - CoC以外（特に戦闘重視システム）は「戦闘要因」が多い可能性
- **仮説2**: CoC6版とCoC7版で違いはあるか？
  - ルールの違いによる時間管理への影響
  - 版ごとのプレイヤー層の特性の違い
- **仮説3**: 戦闘重視システム（D&D、SW2.5、DX3rd）は時間超過しやすい？
- **仮説4**: シーン制システム（シノビガミ）は時間管理がしやすい？
- **分析**: システム別（CoC vs それ以外、主要システム別）の時間超過原因の違い

**2. 形態による時間管理の違い**
- **仮説**: オフラインの方が時間意識が高い？（会場時間の制約）
- **仮説**: オンラインはRP時間が長引きやすい？（テキストセッションの場合）
- **分析**: 形態別の時間超過原因、対処法の違い

**3. 経験年数と時間管理スキルの関係**
- **仮説**: 経験が長いほど時間管理が上手い？
- **分析**: 経験年数別の時間超過頻度、工夫の違い
- **発展**: 初心者向け/上級者向けのコツの整理

**4. PL側の時間管理意識**
- **仮説**: GMだけでなくPLの意識も重要？
- **分析**: PL中心の回答者の時間意識の理由
- **発展**: PLができる時間管理協力の提案

**5. テキストセッション vs ボイスセッション**
- **分析**: 自由記述から「テキスト」「ボイス」に関する言及を抽出
- **比較**: それぞれの時間管理の課題と工夫

**6. 時間管理と遊びの質の関係**
- **問い**: 時間を厳守することで満足度は下がるのか？
- **分析**: 時間意識が高い人の満足度に関する記述
- **仮説**: 適切な時間管理が満足度を高める可能性

**7. キャンペーン vs 単発**
- **分析**: 形態別の時間管理手法の違い
- **仮説**: キャンペーンの方が予備日確保などの柔軟な対応が可能？

#### 3.5.2 追加分析の優先順位付け
1. データから明確に導き出せるもの
2. 同人誌読者にとって有用性が高いもの
3. 分析コストが比較的低いもの

上記の観点から、実施する追加分析を決定する。

## 付録B: 想定される発見と考察の方向性

### B.1 仮説と検証

**仮説1**: 経験年数が長いほど時間管理が上手い
- **検証**: 経験年数×時間超過頻度のクロス集計
- **予想**: 7年以上の経験者は時間超過が少ない？

**仮説2**: GMの方がPLより時間意識が高い
- **検証**: 参加立場×終了時間意識のクロス集計
- **予想**: GM経験者の方が「常に意識している」割合が高い？

**仮説3**: オフラインの方が時間厳守の意識が強い
- **検証**: 参加形態×終了時間意識のクロス集計
- **予想**: オフラインは会場時間の制約で意識が高い？

**仮説4**: CoCとそれ以外で時間管理の傾向が異なる
- **検証**: `isCoC`フラグによる2群比較
- **予想**: CoCはRP要因が多く、それ以外は戦闘要因が多い？

**仮説4-2**: CoC6版とCoC7版で違いがある
- **検証**: CoC6版 vs CoC7版の時間意識・時間超過頻度の比較
- **予想**: 版によるルールの違いが時間管理に影響？

**仮説4-3**: システムにより時間超過の原因が異なる
- **検証**: 主要システム別の時間超過原因の分布
- **予想**: 戦闘重視（D&D/SW/DX）→戦闘要因、RP重視（CoC/エモクロア）→RP要因

**仮説5**: 時間管理の工夫をしている人ほど超過が少ない
- **検証**: GM_時間意識工夫の有無×時間超過頻度
- **予想**: 工夫している人の方が超過が少ない？

### B.2 同人誌で伝えたいメッセージ案

1. **時間管理は楽しさの敵ではない**
   - 適切な時間管理が満足度を高める
   - 時間を守ることで全員が気持ちよく遊べる

2. **GMだけでなくPLも協力が大切**
   - 時間意識はGMだけの責任ではない
   - PLができる協力方法の提案

3. **システムや形態に応じた時間管理**
   - 一律の方法ではなく、状況に応じた工夫

4. **初心者でもできる基本のコツ**
   - 難しい技術ではなく、すぐ実践できる方法

5. **柔軟性も大切**
   - 時間厳守と満足度のバランス
   - 予備日や調整の重要性
